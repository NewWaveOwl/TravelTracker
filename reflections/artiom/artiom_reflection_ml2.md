# Reflection
After finishing Milestone 2, I realized that an AI workflow needs more supervision and more deliberate, explicit prompts. With my first prompt, the AI did more than I asked because I allowed it to think too much. After this miscommunication, I understood the value of different models and that specific models should be applied to specific cases: extended thinking for code review and documentation, medium for writing code, and light and fast for quick questions.

I also found it helpful and insightful to brainstorm the architecture and the actual implementation of the code with AI. During development, I realized that a single Transport model wouldn’t work for what we were doing. It would be overloaded if it included places/stops, arrival times, and departure times. So I split it into three models: TransportMode (like bus, plane, train, etc.), TransportRoute, which has a time and a transport mode, and RoutePoint, which is either a stop, an accommodation, or an attraction, and which can belong to a TransportRoute.
